网课助手 · 装到手机上

不用装安装包：用浏览器打开一次，然后「添加到桌面」，以后一点就开，还能自动更新。
直接打开网课助手

华为 / 荣耀（鸿蒙 HarmonyOS）推荐这样

  1. 用 华为浏览器 打开本页（微信里打开的话，点右上角「…」→ 用浏览器打开）
  2. 点下方「直接打开网课助手」，确认能正常用、能输密钥
  3. 浏览器底部/右上角菜单 →「添加到桌面」（有的版本叫「添加书签」→ 桌面书签）
  4. 以后从桌面图标一点就开，跟 App 一样；我更新后，你下次打开就是新版
鸿蒙 5 / 纯血鸿蒙（NEXT）不能用安卓 apk，用这个方法就行，功能一样是全的。

安卓手机 / 平板

  1. 用 Chrome 或 Edge 打开本页 → 点「直接打开网课助手」
  2. 浏览器右上角 ⋮ →「添加到主屏幕」
  3. 桌面会出现「网课助手」图标，以后点图标打开
也可以装 网课助手.apk（发行方发的安卓包），两者数据不互通，选一种长期用就好。

iPhone / iPad

  1. 必须用 Safari 打开本页（微信里打开先点「用Safari打开」）
  2. 点下方「直接打开网课助手」，确认能用
  3. 底部 分享按钮（方框向上箭头）→「添加到主屏幕」→ 添加

电脑（Windows / Mac）

  1. 直接在浏览器打开本页就能用全部功能（含本地 OCR 的除外）
  2. 想要最强功能，用发行方发的桌面版（自带本地 OCR 服务）

第一次用要做什么

  1. 打开后弹出授权窗口，输入发行方给你的密钥（形如 XXXX-XXXX-XXXX）
  2. 填名字 → 确认，左上角会显示到期天数
  3. 数据存在这台设备的浏览器里；换设备/换浏览器用「数据与设置 → ⬇ 备份 / ⬆ 导入」搬
